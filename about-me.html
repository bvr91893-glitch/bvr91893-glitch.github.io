What This Page Shows

Accessibility point of view

Accessibility Is Not Extra. It Is Lived Experience.

Accessibility is not just a feature. Bryan's class work uses accessibility as part of the foundation, so pages are easier to navigate, read, and understand from the start.

Design point of view

Practicality Over Pretty

When Bryan designs web pages, he keeps accessibility in mind. His motto is "practicality over pretty," because a website should not only look good; it should work well for real people.

Bryan believes accessible design should be clear, dependable, and usable with assistive technology. A page should make sense to someone using a screen reader, keyboard, magnification, or any practical access tool that helps them participate fully.
